# Wadamesh-Lua-Apps-for-P4,Wio L2,T-Deck,Others (Tested on P4 and Wio L2) 
Basic Calculator App (Beta) Calc9.4.lua     
   Simple calc app with error checking added. 

Basic Checklist App (Beta) Jot2.4.lua   
   Allows for a editable checklist, scroll-able, check/uncheck, delete entries

Red/White Phone Light App (Beta) Light.lua   
   Good for finding keys, or for astronomy, tactical needs at night. 
   Adjustable brightness
   
Notes App beta 2.4  Notes.lua      (Credit to rock.paper.scissors for code) 
   Follows basic "CRUD" format  
   Allows for multiple notes up to 150 characters , fully editable, or duplicatable
   (Can send notes to contact list, currently filterd to companions only) 

PomoTimer2.6- Works on P4 and smaller touch screens too.  If you have a P4, audio 
files can be played if named and placed in  "sd:/Music/notification.mp3" else defaults
to the beeper.   Focus time, short break and long break time adjustable, screen sleep can be toggled off. 

Journal2.13 Notes app (see above) updated to include favorites list that sorts to the top of the contact list,
(requires wadamesh beta102), a Journal mode that allows date stamped file names and file sizes up to 750 
characters (send is blocked due to meshcore limitations).
